# Velora

Velora is a full-stack travel platform designed for browsing and booking tours.

---

## 🚀 About the Velora
Velora is built as a full API-based application that allows users to explore available tours, search for tours, view complete tour details, and submit booking requests.

The platform also provides detailed information about hotels and flights related to each tour.

---

Velora is developed using a separated frontend and backend arvhitector
